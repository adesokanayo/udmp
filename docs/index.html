You should be free to take your data out of any SaaS system.

Today that is very hard to do. UDMP, the Universal Data Migration Protocol, is an open format and a set of tools that make it possible: relationships intact, attachments included, no vendor permission required.

The Data Freedom Manifesto

Every business runs on software it rents. The customers, the deals, the tickets, the issues, the orders, the years of notes and files: all of it sits inside someone else's product. Getting it in is effortless. Getting it out is a project nobody budgets for.

The export button gives you a CSV with the relationships stripped out. The API is rate-limited, paywalled on your plan, or both. Attachments come as links that expire. Rich text comes in a format only the vendor reads. None of this is an accident, and none of it is necessary.

We believe:

  1. Your data is yours. Not a copy of it, not a flattened summary of it. The whole graph, with every link between records, in a form you can use without the product that held it.
  2. Leaving should be a weekend, not a quarter. A complete, faithful export of a mid-size tenant should take hours, run unattended, and need no support ticket.
  3. Portability needs a format, not a promise. Regulation can require exports to be "structured and machine-readable". Only a shared, open specification makes that testable.
  4. Nobody should wait for vendor cooperation. The APIs customers already pay for are enough. Adapters are built by the people who need them, using only documented access, and they work today.
  5. Switching costs should be visible. If a vendor makes leaving hard, that should be measured, published and comparable, so buyers can see it before they sign.
  6. Openness should be rewarded. A vendor that ships a first-party exporter or importer earns the badge and the goodwill. This is not a war on vendors. It is a standard they can adopt.

Initiated by Ayo Adesokan, November 2026. Add your name by opening a pull request.

How it works

UDMP has two halves: a bundle format that describes itself completely, and an adapter contract so that any exporter can feed any importer. N sources plus M targets, instead of N × M bespoke migrations.

A bundle

export_bundle/
├── udmp-manifest.json     schema, relationships, file index, provenance, checksums
├── data/
│   ├── account/00001.ndjson
│   ├── contact/00001.ndjson
│   └── deal_contact/00001.ndjson    junction object for many-to-many
├── blobs/
│   └── sha256-a8d5d8…f8.pdf         content-addressed attachments
└── meta/dropped.ndjson              anything that could not be carried
Self-describingEvery object declares its primary key, every field its type, every relationship its cardinality. Custom fields are first-class.
RelationalForeign keys are typed references. A validator proves there are no dangling links before you import.
StreamableNewline-delimited JSON in chunks. Gigabytes export and import with constant memory.
HydratedAttachments are downloaded into the bundle and stored by hash. Rich text becomes Markdown with the original preserved.
SemanticObjects carry tags like crm.contact or work.issue, so an importer that has never seen the source still knows what it is looking at.
VerifiableThree conformance levels: Schema, Relational, Hydrated. udmp validate reports the one you actually have.

Try it

git clone https://github.com/adesokanayo/udmp && cd udmp
pnpm install && pnpm build

node packages/cli/dist/bin.js validate examples/hubspot-sample
node packages/cli/dist/bin.js to-sqlite examples/hubspot-sample crm.sqlite

UDMP_LINEAR_API_KEY=lin_api_… node packages/cli/dist/bin.js export --adapter linear --out ./backup

Run that export weekly into SQLite and you own a queryable copy of your own data before you ever need to switch.

The SaaS Exit Score

A public, reproducible 100-point index of how hard each vendor makes it to leave: API access, schema introspection, relational integrity, export throughput, and attachment portability, 20 points each. Every score cites public evidence, and vendors can dispute by pull request.

VendorPlanScoreGradeWhat holds it back
LinearStandard85BRelationships implicit in the graph rather than declared; uploads need refreshed auth.
HubSpotProfessional75BAssociations only in batches of 100; bulk export is flat CSV; file URLs expire.
